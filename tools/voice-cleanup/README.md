# تنقية صوت الريلز

يأخذ تسجيلاً صوتياً (رسالة صوتية `.oga` أو `.mp3` أو `.wav`) أو فيديو، ويخرج صوتاً نظيفاً جاهزاً للريلز بصيغة WAV.
هذه إعدادات النسخة النهائية **B2** من ريلز ⴰⵖⵎⵉⵙ (40 ث).

## الاستعمال
```sh
pip install -r requirements.txt      # يحتاج أيضاً ffmpeg
python3 voice_cleanup.py hook.oga    # → out/hook.wav
```

| الأمر | النتيجة |
|---|---|
| `python3 voice_cleanup.py hook.oga` | صوت أعمق بأسلوب الراوي ومنقّى (B2) |
| `python3 voice_cleanup.py clip.mp4 -o out/voice.wav` | يأخذ الصوت من فيديو |
| `python3 voice_cleanup.py hook.oga --no-voice-change` | تنقية فقط، بطبقة الصوت الأصلية |
| `python3 voice_cleanup.py hook.oga --pitch 0.81` | أقل عمقاً (قريب من النسخة A) |

## إعدادات B2
- **الطبقة** `--pitch 0.76`: من حوالي 135Hz إلى حوالي 100Hz. استعمل `0.81` لنسخة A (حوالي 110Hz).
- **حجرة الصوت** `--formant 0.90`: صوت أكبر وأكثر ثقة.
- **لحن الكلام** `--contour 0.85`: أداء أثبت قليلاً، والنطق واللكنة كما هما.
- **ضد الخشونة**: تنعيم تتبّع الطبقة (median 7 ثم متوسط 5). اهتزاز الطبقة أقل بحوالي 30% من النسخة B.
- **ضد الأزيز**: لادورية أعلى فوق 3.5kHz، وتخفيف الحدة فوق 6kHz. الترددات العالية أخفض بـ 3.4 dB.
- **ضد الرنين**: لا صدى. الصدى القصير (28/47ms) في النسخة B هو الذي أعطى الطابع المعدني.
- **سلسلة ffmpeg**: إزالة ضجيج خفيفة، و+1.5dB عند 110Hz، و−3dB عند 300Hz، و+2dB عند 2.5kHz، وde-esser، وضغط 3.5:1، ثم loudnorm بمرورين إلى **−16 LUFS**.

## ملاحظات
- حوّل دائماً من التسجيل **الأصلي**، لا من صوت عولج من قبل، حتى لا تتضاعف المعالجة.
- عند المزج مع الموسيقى في الريلز، اجعل المزيج النهائي −14 LUFS.
- مجلد `out/` غير محفوظ في المستودع.
