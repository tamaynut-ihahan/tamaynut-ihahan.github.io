# ريلز ⴰⵖⵎⵉⵙ التعريفي (40 ث، 1080×1920)

ريلز يعرّف بـ ⴰⵖⵎⵉⵙ في خمسة مشاهد، مبني على تسجيل صوتي **واحد** للنص كاملاً (`SCRIPT.txt`)، مع ترجمة بتيفيناغ متزامنة مع الكلام، وموسيقى أصلية مولّدة برمجياً.
الخطوط والشعار والمعيّن مأخوذة من `../aghmis-video/assets/` ولا تُنسخ هنا.

## إعادة البناء
المتطلبات: ffmpeg، وNode 18+ مع Playwright (`NODE_PATH=$(npm root -g)`)، وPython 3 مع `numpy scipy pyworld soundfile`.

```sh
python3 align.py <التسجيل.m4a>   # → out/recording.wav + out/align.json (جدول: كل مقطع كلام ونصه)
python3 prepare_voice.py         # → out/voice/*.wav (منقّاة، −16 LUFS) + out/timeline.json
python3 music.py                 # → out/music.wav
node render.js                   # → out/aghmis_reel_40s.mp4 (~2 دقيقة)
node render.js --stills 1.5 18   # لقطات للمراجعة
```

مجلد `out/` غير محفوظ في المستودع.

## كيف تُضبط المزامنة
1. **`align.py`** يقسم التسجيل عند الوقفات (‎−35 dB، ‏0.25 ث على الأقل)، ويعدّ المقاطع الصوتية في كل جزء (ذروات طاقة الحروف المتحركة)، ثم يطابقها مع مقاطع كلمات `SCRIPT.txt` كلها دفعة واحدة. لا يقع جزء واحد بين مشهدين.
2. **`config.json`** يحدد لكل مشهد:
   - `cut`: بداية المقطع ونهايته في التسجيل الأصلي، أي 0.15 ث قبل أول كلمة وبعد آخر كلمة.
   - `subs`: مجموعات الترجمة، وكل مجموعة قائمة ببدايات الأجزاء التي تُعرض معاً، مأخوذة من جدول `align.py`.
3. **`prepare_voice.py`** يضع كل نص قبل بداية نطقه بـ 0.06 ث.

لتسجيل جديد: شغّل `align.py`، وانقل الأوقات من الجدول إلى `cut` و`subs`، ثم أكمل الأوامر. ابدأ مجموعة ترجمة جديدة عند كل فاصلة أو نقطة، أو حين يتجاوز النص سطرين تقريباً.

## الإعدادات المستعملة في النسخة المنشورة
- **التوقيت**: 0.8 ث قبل أول كلمة، و1.4 ث موسيقى بين المشاهد، والخاتمة حتى 40 ث.
- **الصوت** (`voice_chain` في `config.json`): تمرير عالٍ عند 80Hz، وإزالة ضجيج خفيفة، و+1.5dB عند 200Hz، و−1.5dB عند 350Hz، و+2dB عند 3.5kHz، وde-esser، وضغط 3:1، ثم loudnorm بمرورين إلى −16 LUFS. لا تغيير في طبقة الصوت. لتعميق صوت، استعمل `../voice-cleanup/`.
- **الموسيقى**: سلم خماسي A C D E G، وأوتار منقورة، وبندير خفيف، و96 BPM. تنخفض 15 dB تحت الصوت، ويظهر لحن أعلى في الفواصل والخاتمة.
- **المزيج والتصدير**: ‎−14 LUFS، وH.264 بـ CRF 26 وحد أقصى 2.5 Mb/s، وAAC بـ 128k. الحجم حوالي 3.4 MB، مناسب لفيسبوك وواتساب.
