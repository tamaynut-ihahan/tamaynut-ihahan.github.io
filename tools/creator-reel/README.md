# ريلز صانع محتوى (1080×1920)

ريلز من مجموعة صور لصانع محتوى، لينشره على فيسبوك. **عمل مستقل**: لا شعار ولا ألوان ولا خطوط تخص تاماينوت.
تتتابع الصور مع تكبير بطيء وتلاشٍ متقاطع. وإن لم تكن الصورة بنسبة الشاشة 9:16 تظهر كاملة فوق خلفية ضبابية منها، فلا يُقص منها شيء. يظهر اسم صانع المحتوى وسطر تحته في الثواني الأولى، وفي آخر 4 ث بطاقة ختام فيها اسمه ودعوة للمتابعة بأيقونة فيسبوك. الخط DejaVu Sans من خطوط الجهاز. والموسيقى أصلية يولّدها `music.py`، فلا مشكلة حقوق عند النشر.

## المدخلات (`in/`، غير محفوظة في المستودع)
- `in/photos/`: الصور (JPG أو PNG أو WebP). تُرتب بأسمائها، فسمّها `01.jpg` و`02.jpg` ... بالترتيب الذي تريده. مدة كل صورة تساوي المدة الكلية مقسومة على عدد الصور. لا تضع فيها لقطات شاشة.
- موسيقى: `out/music.wav` من `music.py`، أو أي ملف صوتي يرسله صاحب الطلب، أو `""` لفيديو صامت.

## الإعدادات (`config.json`)
- `photos`: مجلد الصور.
- `music` و`musicStart`: ملف الموسيقى، وبداية المقطع منها بالثواني.
- `duration`: مدة الفيديو بالثواني.
- `creator`: اسم صانع المحتوى كما يكتبه هو.
- `tagline`: السطر تحت الاسم في البداية (`""` لإخفائه).
- `cta`: السطر تحت الاسم في بطاقة الختام، بأيقونة فيسبوك (`""` لإخفائه).
- `fit` (اختياري): `auto` (الافتراضي)، أو `cover` لملء الشاشة بقص الصور، أو `contain` لإظهار الصور كاملة دائماً.
- `output`: اسم الملف الناتج.

اللغة التي يطلبها صاحب الحساب هي لغة النصوص، فالفرنسية مثلاً: `Créatrice de contenu` و`Suivez-moi sur Facebook`.
**التوقيت** في الكائن `TL` في `index.html`: ظهور الاسم واختفاؤه، ومدة بطاقة الختام، ومدة التلاشي، ونسبة التكبير.

## الإخراج
المتطلبات: ffmpeg، وPython 3 مع numpy وscipy، وNode 18+ مع Playwright (`NODE_PATH=$(npm root -g)`).

```sh
python3 music.py 25 8                                        # موسيقى لـ 25 ث و8 صور (مقطع لكل صورة) → out/music.wav
NODE_PATH=$(npm root -g) node render.js --stills 1.5 12 23   # لقطات للمراجعة → out/still_*.png
NODE_PATH=$(npm root -g) node render.js                      # → out/<output> (~دقيقة)
```

`render.js` يتوقف إن لم تُحمَّل الخطوط أو إحدى الصور. قبل التسليم راجع اللقطات: ألا يغطي النص وجهاً، وأن الاسم لم يُقص.
الترميز بـ H.264 (Main 4.0) بـ CRF 27 وحد أقصى 2.5 Mb/s، والصوت AAC بـ 128k ومستواه ‎−14 LUFS.

## بعد التسليم
احذف `in/` و`out/` كلياً، ولا تحفظ اسم صانع المحتوى ولا صوره في المستودع: أعد `config.json` إلى قيمه العامة.
