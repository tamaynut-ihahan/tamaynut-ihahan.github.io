# عناصر الهوية

المرجع الكامل: **`identity-guide.html`** (دليل الهوية البصرية v5، 2026-09-29). افتحه في المتصفح: الألوان، والخطوط وأحجامها، والشعاران، والصفحة والشبكة، وقوالب الأبواب، والصيغة القانونية للإصدارات، وقائمة التحقق قبل الإخراج.
هذا المجلد مستثنى من بناء الموقع (`_config.yml` ← `exclude`).

## الشعارات (`logos/`)
- `tamaynut.png`: شعار منظمة تاماينوت بألوانه الأصلية. على خلفية داكنة يوضع داخل لوحة فاتحة.
- `aghmis.png`: الشعار الرسمي لـ ⴰⵖⵎⵉⵙ ⵏ ⵜⵎⴰⵢⵏⵓⵜ للخلفيات الفاتحة، الأزرق والكحلي (2272px).
- `aghmis-white.png`: النسخة البيضاء بخطوطها الذهبية للخلفيات الداكنة (700px).

يُستعمل الملف كما هو: لا تُغيَّر ألوانه ولا يُمدَّد، ولا توضع فوقه زخرفة.

## الخطوط (`fonts/`)
- `Adlis-tt.ttf`: لكل ما يُكتب بتيفيناغ (© IRCAM). **نسخة TrueType**: النسخة الأصلية CFF قد تُضمَّن في PDF كـ Type 3 فتظهر مشوّهة في قارئات الهاتف، فلا تُستعمل.
- `Tajawal-Regular.ttf` و`Tajawal-Medium.ttf` و`Tajawal-Bold.ttf` و`Tajawal-Black.ttf`: للعربية واللاتينية (ترخيص SIL OFL، انظر `OFL.txt`).

لا خط ثالث.

## الألوان
| اللون | الرمز | الاستعمال |
|---|---|---|
| الأزرق | `#1F56C0` | العناوين، الأسماء، الجذور |
| الكحلي | `#1A2B5E` | النص، الشريط السفلي، شارة رقم الصفحة |
| الذهبي | `#E9B84A` | تشديد فقط: الشريط القصير، المعينات، الأرقام. ليس لون نص |
| الأحمر | `#C9443A` | المعين الداخلي ولمسات صغيرة. لا يُستعمل للنص |
| الكريمي (الورق) | `#F3EEE3` | خلفية الصفحات |
| الكريمي الفاتح | `#FBF7EE` | النص فوق الأزرق، البطاقات |
| الرملي | `#D8CFBD` | الخط الفاصل بين الشعارين |

التدرجات الأخف: الكحلي بشفافية (20% للخطوط، 60–75% للنصوص الثانوية)، لا لون رمادي جديد.

## الزخارف (`motifs/`)
- `diamond.svg`: المعيّن (كريمي، ذهبي، أحمر، ونقطة بلون الورق)، أساس شريط المعيّنات.
- `door_leaf.svg`: مصراع الباب الأمازيغي (من فيديو الإطلاق).
