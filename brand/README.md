# عناصر الهوية

ملفات محفوظة للتصاميم القادمة. هذا المجلد مستثنى من بناء الموقع (`_config.yml` ← `exclude`).

## الشعارات (`logos/`)
- `tamaynut.png`: شعار منظمة تاماينوت (815×367، خلفية شفافة)
- `aghmis.svg` / `aghmis.png`: شعار ⴰⵖⵎⵉⵙ ⵏ ⵜⵎⴰⵢⵏⵓⵜ للخلفيات الفاتحة (أزرق `#1F56C0` وكحلي `#1A2B5E`)
- `aghmis-light.svg` / `aghmis-light.png`: نسخة كريمية `#F3EEE3` للخلفيات الداكنة

حروف شعار ⴰⵖⵎⵉⵙ في ملفات SVG محوّلة إلى مسارات، فلا تحتاج إلى تثبيت الخط.

## الزخارف (`motifs/`)
- `diamond.svg`: المعيّن (أبيض وذهبي وأحمر)، وهو أساس شريط المعيّنات في الصور والفيديو
- `door_leaf.svg`: مصراع الباب الأمازيغي

## الخطوط (`fonts/`)
- `Adlis_otf.ttf`: لكل نص بتيفيناغ (© IRCAM)
- `Tajawal-Regular.ttf` و `Tajawal-Bold.ttf`: للعربية واللاتينية (ترخيص SIL OFL، انظر `OFL.txt`)

## الألوان
